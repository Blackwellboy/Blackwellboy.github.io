What this is for

Most people do not have the hardware, or the days, to work out why a local model is misbehaving. Whether the problem is the model, the quant, the template, or the serving stack usually takes a fleet and a weekend to answer properly.

The work here is doing that crunching once and publishing the answer with the raw data attached, so the next person spends ten minutes instead of three days.

Tools

model-serving-minefield

A registry of serving and config bugs that produce confidently wrong measurements: chat templates, tool parsers, reasoning fields, quantization kernel paths, container toolchains, eval harnesses. 32 traps, each led by the symptom you would actually observe, with the check that catches it and the fix.

minefield-doctor

One stdlib-only Python file. Point it at your OpenAI-compatible endpoint and it diagnoses the endpoint against the registry. Read-only, no install, no dependencies.

Laguna operators guide

How to actually run Laguna S 2.1 in production: config, thinking control, tool format, known failure modes. Every figure in it re-derived from the raw logs before publication.

Selected work

  • 20-cell tuning sweep: selected the production serving config by measurement; the winning cell reached 26.2 tok/s single-stream median and 61.65 tok/s aggregate at concurrency 4. Every losing cell is published. DFlash K=7, max-num-seqs=32; Hermes bench v1 short subset; NVFP4 on vLLM; TTFT 322 ms
  • 12-hour production soak: 3,096 HTTP-200 turns over 409 sessions with zero crashes; thinking fired on 3 turns (0.097%). Carried upstream in the offlabel guide as external validation. production profile K=7/seqs=32, max_tokens 8192, thinking requested on every turn
  • Thinking-gate study: whether Laguna thinks is a persona-by-task conjunction, not a switch; summarization never fired (0/105) and a 10-rule persona block was the strongest suppressor (3/40). The same grid on Qwen 3.6 35B-A3B fired 400/400, so the suppression is Laguna-specific. 450 logged turns, 10-condition grid, n=40 per condition, 0 HTTP errors
  • HumanEval+ replication: the claimed thinking-ON accuracy gain does not replicate temperature-controlled; ON scored 89.84 vs OFF 90.85 on HumanEval+. 984 requests, 164 problems x 2 arms x 3 seeds, 0 transport errors, evalplus scoring
  • Multi-turn reasoning-stripping mechanism: clients that strip prior-turn reasoning from history silence thinking entirely; with history preserved it fired 10/10, stripped 0/10, in both depth cells. depth 10 and depth 20 conversations, max_tokens 8192, same prompts both arms
